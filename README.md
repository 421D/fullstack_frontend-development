This repository consolidates a collection of **full-stack and frontend-focused projects** spanning **mobile, desktop, web, and mini program ecosystems**.  
It demonstrates practical experience across **UI/UX design, frontend engineering, backend integration, local/cloud data persistence**, and **end-to-end application workflows**.

The projects range from **early-stage frontend practice** to **complete application systems**, covering Android, Java desktop systems, Web platforms, and WeChat Mini Programs.

## Projects Index

### 📱 Android Projects
#### [Daily Finance App（今日理财资讯）](./Android_Projects)

An Android finance management application built with **Java** in **Android Studio**, focusing on structured data display and local persistence.

**Highlights**
- Splash screen with animation / MP4 intro
- RecyclerView-based dynamic list
- Add & manage finance items in real time
- Local JSON storage for offline persistence

**Key Tech:** Java, Android SDK, RecyclerView, JSON, MediaPlayer

### 🖥 Java Desktop Systems
#### [Hotel Management System | 酒店管理系统](./Java_projects)

A **full-featured desktop management system** using **Java Swing + SQL Server**, supporting authentication, room management, billing, and role-based access.

**Highlights**
- Swing-based GUI with modular OOP architecture
- JDBC-driven database operations
- Separate authentication server and main client
- Complete hotel workflow: check-in, dining, billing, checkout

**Key Tech:** Java, Swing, JDBC, SQL Server
